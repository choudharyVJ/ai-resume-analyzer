# AI Resume Analyser 🚀

An AI-powered Resume Analysis platform that helps users improve resumes using modern LLMs, ATS-style analysis, and intelligent suggestions.

Built using:
- Next.js (Frontend)
- Django + DRF (Backend)
- Groq LLM API
- LangChain
- ChromaDB
- RAG Architecture

---

## Features

✅ Resume Upload  
✅ AI Resume Analysis  
✅ ATS Score Estimation  
✅ Skill Gap Detection  
✅ AI Suggestions for Improvement  
✅ Job Description Matching  
✅ RAG-based Context Processing  
✅ Modern Responsive UI  
✅ Authentication Ready
